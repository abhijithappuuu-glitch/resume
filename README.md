# Abhijith B's Portfolio

Welcome to my personal portfolio. This site is built with React.js and serves as a showcase for my projects, education, and experience.

## View Online

Check out the live portfolio: [Abhijith's Portfolio](https://abhijithappuuu-glitch.github.io/resume/)

## Features

- Complete project showcase
- Interactive timeline of education and experience
- 100% Mobile Responsive
- Modern and Clean UI

## Development Setup

To run this project locally:

1. Clone the repository
2. Install dependencies:

```bash
npm install
```

3. Run the development server:

```bash
npm start
```
